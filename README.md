# MARK 57

AI desktop assistant with voice control, HUD command-center GUI, and browser automation.

## Features

- Voice input (Vosk offline STT)
- LLM-powered chat (Pollinations/Kilo Gateway)
- Browser-use agent for web automation
- Image & video generation (Pollinations AI)
- File & system automation
- Futuristic HUD GUI with animated orb

## Setup

```bash
pip install -r Requirements.txt
python main.py
```

## Config

Edit `jarvis.env` to set your name, voice, AI model, and API keys.

## Requirements

- Python 3.10+
- Linux (Kali/Ubuntu)
- Microphone for voice input
